# External Research Follow-ups

These items cannot be completed inside the repository and must be recorded by
the researcher before submission.

## GPU evaluation

- Provision a CUDA-capable host with sufficient memory for the selected local
  model and record the GPU model and driver version.
- Install the project with `.[local-injecagent]` and initialize the InjecAgent
  submodule at the repository-pinned revision.
- Run the pilot gate in `docs/native_injecagent_protocol.md` before any full
  matrix run.
- Retain raw JSON outputs, analysis summary, package versions, and model
  revision hash.

## Technical review

Ask a mentor or instructor to review the following questions:

1. Does the manuscript clearly distinguish an architectural implementation
   from the original CaMeL contribution?
2. Are native tool-choice results kept separate from provenance-specific
   authorized-action replay results?
3. Do the limitations exclude live-service and universal-security claims?
4. Does every quantitative manuscript claim map to a frozen artifact?

## MIT URTC confirmation

The public site currently mixes 2026 conference dates with a stale 2025
technical-paper deadline. Contact the organizers and record the authoritative
2026 information for deadline, template, page limit, anonymity, eligibility,
authorship, acknowledgements, AI-assistance disclosure, and supplementary
material rules before formatting the submission.
